# Presentation storyboard

Format: 16:9, approximately 120 seconds.

1. 0–12s — Hook: “From blank folder to running Expo app.” Show the project name and GitHub clone command.
2. 12–30s — The problem: configuration spread across package.json, Expo Router, NativeWind, TypeScript, and web support.
3. 30–48s — One-command entry: `node setup-project.js`; show the real name and app-type prompts.
4. 48–68s — Clean starter default: Desktop/projects destination and starter choice.
5. 68–88s — Optional authentication: Formik, Expo Constants, login, and signup.
6. 88–105s — Automatic start: `npm run start` from the generated project.
7. 105–120s — Closing lockup: “Build the feature, not the setup.” Include the repository URL and author credit.

Narration: calm, clear, technical, and truthful. No claims beyond the inspected setup pipeline.
