# Social storyboard

Format: 9:16, approximately 120 seconds.

1. 0–8s — Hook: “One command. Clean Expo app. Zero setup spiral.”
2. 8–28s — Show the actual GitHub clone and the launcher command.
3. 28–45s — Type the project name; show the two app-type choices.
4. 45–65s — Show the clean starter default and generated Desktop/projects path.
5. 65–88s — Fast reveal of optional Formik authentication, login, and signup.
6. 88–108s — Show the automatic `npm run start` handoff and project folder.
7. 108–120s — CTA: “Clone it. Choose starter. Start building.” Include the repository URL and BAGSGRAPHICS TECHNOLOGY credit.

Vertical pacing: large readable text, one command per scene, purposeful cursor/typing motion, no static montage.
